> نقشه تعاملی و راهنمای شرکت‌ها، کارخانه‌ها و مسیرهای شهرک صنعتی هرات.

---

## 🌟 Key Features / قابلیت‌های کلیدی

### English
- Interactive vector map navigation
- Enterprise & factory search directory
- Routing & location tracking
- Supabase backend integration

### فارسی
- ناوبری روی نقشه تعاملی و وکتوری
- دایرکتوری کامل جستجوی کارخانه‌ها و شرکت‌ها
- مسیریابی و ردیابی موقعیت مکانی
- یکپارچگی با پایگاه داده ابری Supabase

## 🚀 Getting Started / راه‌اندازی پروژه

### Prerequisites
- Flutter SDK (>= 3.0.0)
- Dart SDK
- Android Studio / VS Code with Flutter extension

### Installation & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/pxf0rge/heratmap-mobile.git
   cd heratmap-mobile
   ```

2. **Install dependencies:**
   ```bash
   flutter pub get
   ```

3. **Run the application:**
   ```bash
   flutter run
   ```
