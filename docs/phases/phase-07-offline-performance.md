# فاز ۷ — آفلاین و کارایی

**وضعیت:** ⬜
**وابستگی:** فاز ۲ (لایه‌ی کش)
**ارزش:** کاربر در شهرک با اینترنت لرزان مواجه است. اپ باید «همیشه چیزی برای نشان دادن» داشته باشد
و نقشه نباید در گوشه‌های بدون پوشش خالی شود.

## اهداف

1. **کش داده‌ی هوشمند:** نمایش فوری داده‌ی دیسک و بعد به‌روزرسانی از شبکه (stale-while-revalidate)،
   با نشانه‌ی واضح «آخرین به‌روزرسانی: ۳ روز پیش» و دکمه‌ی تازه‌سازی.
2. **همگام‌سازی هنگام اتصال:** با برگشتن اینترنت (نیازمند افزودن بسته‌ی بررسی اتصال)، کش به‌روز شود.
3. **برنامه‌ی دانلود نقشه:** انتخاب محدوده‌ی شهرک و دانلود کاشی‌های زوم ۱۴–۱۷ برای استفاده‌ی آفلاین
   + نشان دادن حجم تقریبی و پیشرفت (FMTC این امکان را دارد).
4. **کش تصاویر:** تنظیم `cached_network_image` (حداکثر کش، ارتفاع/عرض مناسب) تا تصاویر شرکت‌ها
   یک‌بار دانلود شوند.
5. **کارایی راه‌اندازی:** `await`های زنجیره‌ای `main` (GetStorage → Supabase → FMTC + ساخت استور)
   موازی/به‌تعویق‌افتاده شوند تا کلید صفحه سریع‌تر بیفتد؛ اندازه‌ی اپ (assets fonts ×۹ وزن) بازبینی شود.
6. **پاک‌سازی حافظه:** مدیریت کش FMTC و کش تصاویر از تنظیمات («پاک‌کردن داده‌های آفلاین»).

## خروجی‌ها

- `lib/core/startup.dart` (اجرای موازی راه‌اندازی)
- ویجت نشانگر وضعیت آفلاین/سن داده
- صفحه‌ی «نقشه‌ی آفلاین» در تنظیمات
- `lib/data/cache/` + به‌روزرسانی مخازن

## معیار پذیرش

- [ ] قطع اینترنت پس از یک بار استفاده: همه‌ی تب‌ها داده نشان می‌دهند + نشانه‌ی آفلاین.
- [ ] زوم/پن روی محدوده‌ی دانلودشده بدون اینترنت، کاشی نشان می‌دهد.
- [ ] زمان تا اولین فریم پس از تغییرات اندازه‌گیری و در سند ثبت شود (هدف: بهتر از وضع قبل).
- [ ] دکمه‌ی پاک‌کردن داده‌های آفلاین واقعاً کش را خالی کند و UI به حالت اولیه برگردد.

## نکات

- افزودن بسته‌ی جدید فقط اگر در فهرست وابستگی‌های مجاز پروژه باشد؛ در غیر این صورت
  با `timeout` و تلاش دوره‌ای ساده پیاده شود (بدون بسته‌ی اضافه).
