# فاز ۸ — مدیریت داده و ورود اطلاعات

**وضعیت:** ⬜
**وابستگی:** فاز ۱
**ارزش:** بزرگ‌ترین ریسک محصول، فنی نیست: **داده**. الان ۱ شرکت در دیتابیس است. تا وقتی
ورود اطلاعات ارزان و قابل‌تکرار نباشد، اپ هرچقدر هم خوب باشد بی‌فایده است.

## اهداف

1. **ورود گروهی (Bulk import):** اسکریپت تبدیل فایل CSV/Excel به SQL/Supabase
   (`scripts/import_factories.dart` یا ابزار پایتون/شل — مطابق ابزارهای موجود پروژه).
2. **اعتبارسنجی داده:** قاعده‌های `docs/PROJECT.md` بخش «قواعد اعتبارسنجی» به‌صورت خودکار:
   مختصات داخل محدوده، تلفن، فاز موجود، تصویر بدون تکرار.
3. **پاک‌سازی داده‌ی فعلی:** حذف فاصله‌ی ابتدایی `" زلال موفق"`، یکتاسازی آدرس تصویر تکراری
   (migration اصلاحی یا به‌روزرسانی در seed).
4. **آپلود تصاویر:** روش استاندارد نام‌گذاری فایل در باکت `images`
   (`factories/<id>-<n>.jpg`) + اسکریپت آپلود به Storage.
5. **جایگزین پنل ادمین:** راهنمای گام‌به‌گام ویرایش داده در Supabase Dashboard
   (چون auth در نسخه‌ی ۱ نداریم) + قالب Google Sheets برای جمع‌آوری داده از میدان.
6. **اختیاری (نسخه‌ی بعد):** اپ ادمین با ورود ایمیل/رمز (Supabase Auth) و RLS نوشتن برای نقش ادمین.
