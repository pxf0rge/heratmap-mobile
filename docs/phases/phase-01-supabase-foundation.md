# فاز ۱ — پایه‌ی Supabase و قرارداد داده

**وضعیت:** ✅ انجام شد
**وابستگی:** ندارد
**ارزش:** بدون این فاز، هر کار بعدی روی بک‌اند حدس‌وگمان است. خروجی، یک بک‌اند «تکرارپذیر» است:
هر کسی بتواند پروژه را از صفر بسازد و همان داده را ببیند.

## اهداف

1. اسکیمای فعلی Supabase به‌صورت **migration قابل‌اجرای مکرر** ثبت شود (تا حالا فقط در داشبورد بوده).
2. RLS و باکت تصاویر صریح و امن تعریف شود (خواندن عمومی، نوشتن فقط با سرویس‌رول).
3. `seed.sql` شامل داده‌ی فعلی (۲ فاز + ۱ شرکت) برای بازسازی سریع محیط.
4. پیکربندی اپ از حالت «هاردکد در main.dart» به `AppConfig` قابل‌تنظیم با `--dart-define` منتقل شود
   تا کلید و آدرس پروژه عوض‌شدنی باشد (تست/استیجینگ/پروداکشن).
5. یک اسکریپت دود (smoke) که سلامت اتصال REST را بدون اجرای اپ چک کند.

## یافته‌های مهم از دیتابیس زنده

بررسی با REST/PostgREST (بدون دسترسی مستقیم به Postgres) سه مشکل واقعی را نشان داد:

1. **کلید خارجی اشتباه** — ثابت `factories_id_fkey` روی `factories.id → phases.id` وجود دارد.
   پیام سرور: `Key (id)=(8) is not present in table "phases"`. یعنی درج هر شرکت جدید خطای `23503`
   می‌دهد و تعداد شرکت‌ها عملاً به تعداد فازها محدود شده است. **این محدودیت باید حذف شود**
   (در migration انجام شده) و با `factories.phase → phases.name` جایگزین شود.
2. **NOT NULL بدون پیش‌فرض** — درج ردیف ناقص با `23502` رد می‌شود؛ migration برای همه‌ی ستون‌های متنی
   مقدار پیش‌فرض می‌گذارد.
3. **RLS روی دیتابیس زنده اعمال نشده** — درج از سمت کلاینت پیش از اعمال migration هم رد می‌شود،
   ولی دلیلش محدودیت‌های جدول است نه سیاست امنیتی. پس از اعمال migration، دلیل رد شدن `401/403` از سمت RLS خواهد بود.

> راهنمای اعمال: [`supabase/README.md`](../../supabase/README.md)

## یادداشت‌ها و بدهی‌های باقی‌مانده

- داده‌ی موجود نیاز به پاک‌سازی دارد (فاصله‌ی ابتدایی نام، تصویر تکراری) → seed آن را تمیز می‌کند،
  ولی ردیف زنده تا اجرای `seed.sql` یا اصلاح دستی تمیز نمی‌شود → فاز ۸.
- `supabase login`/`link` انجام نشده؛ اعمال migration از SQL Editor داشبورد انجام می‌شود.
- `phases.image` برای هر دو فاز تهی است؛ UI باید placeholder داشته باشد (دارد).
- محدوده‌ی مختصات و صحت GPS داده‌ی میدانی باید در فاز ۸ کالیبره شود.
