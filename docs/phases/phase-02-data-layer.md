# فاز ۲ — لایه‌ی داده و مقاوم‌سازی شبکه

**وضعیت:** ✅ انجام شد
**وابستگی:** فاز ۱
**ارزش:** الان هر خطای شبکه به یک پیام فارسی ثابت تبدیل می‌شد و کش هیچ‌وقت کهنه نمی‌شد.
این فاز اپ را در «اینترنت ضعیف» — یعنی وضعیت واقعی کاربر در هرات — قابل‌اعتماد می‌کند.

## اهداف

1. **نتیجه‌ی تایپ‌دار:** جدا کردن «داده‌ی خالی» از «خطا» از «کش کهنه»؛ مثلاً `DataResult<T>`
   شامل `data` و `source` (`network` / `disk`) و سن کش.
2. **کش نسخه‌دار + TTL:** ذخیره‌ی `schemaVersion` و زمان نوشتن در کنار داده؛ داده‌ی قدیمی‌تر از
   حد مشخص «کهنه» علامت‌گذاری شود. کلیدها باید با تغییر مدل خودشان باطل شوند.
3. **تلاش مجدد هوشمند:** retry با backoff و jitter فقط برای خطاهای گذرا (timeout/5xx)، نه ۴xx.
4. **تک‌پرواز (single-flight):** درخواست‌های هم‌زمان برای یک جدول ادغام شوند تا با تاپ‌کردن تب‌ها
   چند بار به شبکه نزنیم.
5. **خطاهای قابل‌ترجمه:** `DataError` با نوع مشخص (`offline`, `timeout`, `unauthorized`,
   `notFound`, `server`, `malformed`, `unknown`) تا UI کلید ترجمه‌ی درست را انتخاب کند.
6. **کلاینت تنظیم‌شده:** timeout درخواست‌ها متمرکز شود.

## تصمیم‌های پیاده‌سازی (و دلیلشان)

1. **کش تازه پیش از شبکه (۵→۱۰ دقیقه):** اگر کش کمتر از `AppConfig.freshCacheAge` قدمت داشته باشد،
   بدون رفت‌وبرگشت شبکه نمایش داده می‌شود؛ دکمه‌ی تازه‌سازی و بنر آفلاین همیشه `forceRefresh` می‌زنند.
   این «stale-while-revalidate» کامل نیست — همگام‌سازی پس‌زمینه هنگام برگشت اینترنت در فاز ۷ تکمیل می‌شود.
2. **فیلتر فاز محلی، نه `eq` سرور:** همه‌ی شرکت‌ها با یک درخواست کش می‌شوند و فیلتر فاز با
   `phaseNamesMatch` انجام می‌شود، چون نگارش نام فاز در دیتابیس (`فاز ۱` / `فاز 1`) قابل تغییر است و
   در حالت آفلاین هم فیلتر فاز باید کار کند. با داده‌ی چند صد ردیفی این انتخاب بهینه‌تر است.
3. **حذف کش per-phase:** یک کلید کش (`factories_all`) جای چندین کلید؛ ساده‌تر و بدون داده‌ی ناهمخوان.
4. **`transientOverride`:** نوع خطا برای کاربر گویا نیست ولی گذرا بودنش مهم است؛ مثلاً نقض کلید خارجی
   (`23503`) از نوع `server` است ولی تکرار بی‌فایده است.
5. **ترجمه‌ها همین‌جا اضافه شدند:** کلیدهای خطا/آفلاین/زمان به هر سه زبان (fa/ps/en) اضافه شد چون
   «خطای قابل‌ترجمه» بدون متن، نیمه‌کاره است. بقیه‌ی رشته‌های هاردکد در فاز ۶ تمیز می‌شوند.
